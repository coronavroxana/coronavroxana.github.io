01 · Health Analytics

Chronic Disease Risk Screening

CDC NHANES + BRFSS · Diabetes & Obesity · Dual-dataset comparison

CatBoost Mann-Whitney NHANES BRFSS Health Analytics
+ details

Problem & Why it matters

Can objective body measurements (waist, arm circumference, height) predict diabetes risk as accurately as a behavioral survey — without lab tests? This project compares two CDC datasets to answer that question, and explores an anthropometric ratio (Waist-to-Arm, WAR) as a possible low-cost screening indicator.

AUC-ROC 0.81
CatBoost · NHANES anthropometrics · 2x precision vs behavioral model

Key Takeaways

Anthropometric measurements match behavioral survey predictive power (0.81 vs 0.80 AUC-ROC) with nearly double the precision (0.57 vs 0.29). WHR and WHeightR outperform BMI as risk indicators. Regression analysis confirms body measurements stratify population risk but cannot replace lab HbA1c for individual diagnosis, which is consistent with clinical practice.

→ View on GitHub

Methodology

  • 01 Loaded BRFSS (253,680 surveys) and NHANES 2021-2022 (6,715 participants with lab HbA1c); merged 4 clinical datasets via participant ID
  • 02 Engineered WAR (Waist-to-Arm Ratio), WHR, WHeightR; applied height-stratified median imputation for 912 missing values
  • 03 Mann-Whitney U hypothesis testing across 5 anthropometric ratios vs HbA1c — all significant (p < 1e-39)
  • 04 Trained CatBoost, Random Forest, Logistic Regression on both datasets with class imbalance handling
  • 05 Cross-dataset comparison on AUC-ROC and Precision; NHANES model achieves 2x precision with 38x fewer observations
  • 06 Regression analysis (Linear + RF) for HbA1c prediction; RMSE 0.94 confirms anthropometrics insufficient for individual diagnosis

Problem & Why it matters

Large manufacturers prevent problems with nine-pillar systems and dedicated teams. Small businesses have the same problems (the same error every month, knowledge that leaves when someone is out, meetings that only put out fires) but none of that infrastructure. This framework keeps the idea and drops the size.

4 pieces, not 9
Five-step ladder · exit test per step · 12-week pilot

Key Takeaways

Each step is earned with evidence, not paperwork. The test for step 3 is simple: the leader takes two weeks off and the routine runs the same.

→ Download preview (PDF)

How it works

  • 01 Five maturity steps, from firefighting to autonomy, each with five conditions and an exit test
  • 02 Four pieces (care, remove losses, people, flow), each with one simple tool
  • 03 A fixed rhythm: 15 minutes daily, 45 weekly, 1 hour monthly
  • 04 Losses counted by hand against a baseline, never projected
  • 05 A 12-week pilot on one process with three go / adjust / stop milestones
  • 06 Rule: if a year of losses is not at least 3× the pilot's cost, it doesn't run

05 · Industrial ML

Gold Recovery Optimization

Zyfra · Heavy industry process prediction

RandomForest Regression sMAPE SPC Process data
+ details

Problem & Why it matters

Zyfra develops efficiency solutions for heavy industry. The goal: predict gold recovery yield across flotation and purification stages to eliminate non-profitable process parameters, the same logic as process control in regulated manufacturing.

sMAPE 11.17%
Final model · custom metric validated against recovery formula (MAE ≈ 0)

Key Takeaways

Chrono-aligned imputation matters more than model complexity when data has temporal structure. Random Forest outperformed Linear Regression and Decision Tree under cross-validation with the custom sMAPE scorer.

→ View on GitHub

Methodology

  • 01 Loaded and merged 3 datasets (train, test, full); verified gold recovery formula with MAE ≈ 0
  • 02 Outlier treatment via quantile filtering (1%–99%); forward-fill imputation aligned to process chronology
  • 03 EDA across extraction stages — compared Au/Ag/Pb distribution, detected zero-anomalies
  • 04 Feature engineering: homologated train/test feature sets, StandardScaler applied post-split
  • 05 Trained Linear Regression, Decision Tree, Random Forest; evaluated with custom sMAPE
  • 06 Final model selection via cross-validation; identified non-profitable parameters for operational review

06 · End-to-end ML

Customer Churn Prediction

Interconnect Telecom · Full pipeline from raw data to business strategy

XGBoost CatBoost AUC-ROC Class imbalance Retention
+ details

Problem & Why it matters

Predict which telecom subscribers will churn so the marketing team can intervene proactively with retention offers. The same ML architecture transfers directly to patient dropout, clinical trial adherence, and subscriber retention in health platforms.

AUC-ROC 78.38%
XGBoost · holdout test set · 5-model comparison

Key Takeaways

Class imbalance doesn't always require resampling — class_weight='balanced' with proper cross-validation seeds preserved data integrity while improving minority-class recall. Feature source matters: contract type was the strongest churn predictor.

→ View on GitHub

Methodology

  • 01 Integrated 4 relational tables (contract, personal, internet, phone); unified into single analytical dataset
  • 02 EDA: distribution analysis, churn rate by contract type, tenure, and service bundle
  • 03 Feature engineering: encoded categorical variables, engineered tenure and service-interaction features
  • 04 Class imbalance handled via class_weight='balanced' and scale_pos_weight — no artificial resampling
  • 05 Trained 5 models: Logistic Regression, Decision Tree, Random Forest, CatBoost, XGBoost
  • 06 Final selection: XGBoost (AUC-ROC 78.38%) with cross-validation; translated risk scores into retention framework
